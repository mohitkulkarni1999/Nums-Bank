NUMS BANK - Modern Digital Banking Platform
==============================================

PROJECT OVERVIEW
----------------
NUMS Bank is a comprehensive digital banking platform built with microservices architecture. 
The system provides a complete banking solution including account management, transactions, 
loans, credit cards, and administrative operations. The platform is designed to be secure, 
scalable, and user-friendly with both customer-facing and admin interfaces.

TECH STACK
----------
Frontend:
- React 19.2.0 with Vite
- Tailwind CSS for styling
- React Router for navigation
- Lucide React for icons
- React Hot Toast for notifications
- Context API for state management (Auth, Theme)

Backend Microservices:
1. account-service (Port 8082)
   - Spring Boot 3.x
   - Spring Data JPA
   - MySQL database
   - REST API for account operations

2. transaction-service (Port 8083)
   - Spring Boot 3.x
   - Spring Data JPA
   - MySQL database
   - REST API for transactions, beneficiaries, loan payoff

3. loan-service (Port 8084)
   - Spring Boot 3.x
   - Spring Data JPA
   - MySQL database
   - REST API for loan operations, EMI calculation

4. admin-service (Port 8085)
   - Spring Boot 3.x
   - Spring Data JPA
   - MySQL database
   - REST API for admin operations, user management, reports

Database:
- MySQL for data persistence
- Redis for caching (configured)
- Database indexing for performance

Architecture:
- Microservices architecture
- RESTful API communication
- JWT authentication
- Role-based access control (USER, ADMIN)

CHALLENGES OVERCOME
-------------------
1. Loan Payoff Integration
   - Challenge: Balance deduction not working during loan payoff
   - Solution: Integrated account selection and balance deduction logic
   - Added account selection in loan payoff modal
   - Implemented proper error messages for insufficient funds

2. Database Constraints
   - Challenge: next_emi_date null constraint error
   - Solution: Modified entity to allow null values
   - Updated loan payoff logic to handle null dates

3. Authentication Flow
   - Challenge: Login redirect issues
   - Solution: Fixed ProtectedRoute redirect logic
   - Updated default redirect paths
   - Implemented proper role-based routing

4. UI/UX Improvements
   - Challenge: Dashboard looking AI-generated
   - Solution: Simplified design to look more natural
   - Removed excessive gradients and animations
   - Used cleaner typography and spacing

5. Landing Page
   - Challenge: Creating industry-standard landing page
   - Solution: Built comprehensive landing page with:
     - Hero section with banner image
     - Features section
     - Services section
     - Testimonials
     - Contact form
     - Responsive design
     - Dark/light mode support
